#  Amazon Sales & Product Analytics Dashboard

An end-to-end data analytics project designed to evaluate Amazon sales performance, product category trends, and customer review behavior using SQL and Power BI.

---

##  Tech Stack & Tools
- **SQL:** Data extraction, manipulation, and aggregations.
- **Power BI:** Interactive dashboards, KPI cards, and data visualization.
- **Microsoft Excel:** Initial data inspection and formatting.

---

## Project Overview
This project dives deep into e-commerce data to uncover key business insights:
- **Sales Trends:** Tracked monthly revenue growth and identified peak sales seasons.
- **Product Analysis:** Highlighted top-performing categories and high-demand products.
- **Customer Ratings:** Analyzed customer feedback patterns to measure product satisfaction.

---

##  Repository Structure
- `Amazon_Sales_Data.sql`: Contains all the SQL queries used for data extraction and analysis.
- `Amazon_Dashboard.pbix`: The interactive Power BI dashboard file visualizing overall metrics.

---

##  Key Dashboard Features
- **Dynamic Slicers:** Filter data seamlessly by region, product category, and date ranges.
- **Visual KPIs:** Quick-glance metrics for total sales, average ratings, and units sold.
